# T0 — Diagnóstico inicial (não modificar nada)

Estamos iniciando o projeto Neon Rush 3D em um projeto Unity já existente.

Faça somente um diagnóstico focado, sem modificar arquivos, cenas, objetos, configurações ou pacotes.

1. Confirme a conexão com o Unity Editor usando as ferramentas MCP disponíveis.
2. Identifique o projeto e a cena atualmente aberta, se essas informações estiverem acessíveis.
3. Liste as ferramentas MCP relevantes para:
   - consultar a cena e a Hierarchy;
   - criar ou modificar GameObjects;
   - adicionar/configurar componentes;
   - executar ações no Editor;
   - consultar Console/erros.
4. Verifique, apenas nos arquivos de configuração relevantes, a versão Unity e o sistema de entrada configurado.
5. Informe se já existem cenas, scripts ou convenções que afetem a implementação.
6. Proponha um plano mínimo para T1.

Não presuma que uma ferramenta existe: use somente ferramentas efetivamente disponibilizadas pelo servidor MCP. Não execute testes nem altere nada nesta tarefa.

Entregue um relatório com:
- conexão MCP: confirmada/não confirmada;
- cena ativa;
- ferramentas relevantes encontradas;
- versão e sistema de entrada, se confirmados;
- riscos ou incompatibilidades;
- plano proposto para T1.

Aguarde minha autorização antes de implementar.
